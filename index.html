How detection and classification work

  1. Validate the file is real FITS data
  2. Clean it with the training pipeline's preprocessing
  3. Cut it into 15-minute windows
  4. Detect and classify candidate bursts by type with the planned YOLOv8 model
  5. Report each burst's type, UTC time range, frequency range, and confidence
